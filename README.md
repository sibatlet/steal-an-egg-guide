# EGGQUEST — Steal An Egg

Неофициальный русскоязычный фан-гид. Статический сайт без сборки.

## Публикация на GitHub Pages

1. Создать отдельный публичный репозиторий `steal-an-egg-guide` в аккаунте `sibatlet`.
2. Загрузить только файлы из этой папки в корень ветки `main`.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
4. Дождаться успешной публикации и открыть адрес, показанный GitHub Pages.

Не загружать родительскую папку «Кирилл» или её `.git`.

## Источник

Описание игры: https://www.roblox.com/games/107778070777162/Steal-An-Egg
Автор: and Collect Rare Pets. Проверено 2026-09-13.
Советы о порядке знакомства с механиками — редакционные рекомендации.
Главная иллюстрация создана специально для фан-сайта и не является скриншотом Roblox.

Локальный просмотр: `python3 -m http.server 8765` из этой папки.

## Каталог питомцев

`pets.html` — поиск по английским именам и русским подсказкам, фильтры, сортировка,
раскрывающиеся характеристики. Главная страница отправляет запрос в каталог.
`data/pets.json` содержит снимок публичной фан-вики, а не прямые данные сервера Roblox.
Все записи `Module:Pets/Data` дополняются структурированными карточками `Detail`.
Противоречивый доход записывается как `null`, варианты остаются в `incomeVariants`.
Неизвестные поля не подменяются нулями. Событийные питомцы могут быть недоступны сейчас.
Изображения загружаются с Fandom CDN, ссылки на страницы файлов указаны в карточках.
Факты и адаптированные подписи распространяются по условиям CC BY-SA источника;
отдельные изображения могут иметь собственные условия использования.

Обновление: `python3 scripts/update_pets.py`. Нужен Python 3.9+ и доступ к публичному
MediaWiki API. Без сторонних библиотек. Скрипт не выполняет Lua или HTML вики,
проверяет полноту данных и заменяет JSON только после успешного завершения.
При потере более 10% питомцев или 20% заполненных характеристик обновление прерывается.
Проверки: `node scripts/test_catalog.js` (Node 18+).

В Codex создана автоматизация `eggquest`: по воскресеньям в 22:00 Asia/Bangkok.
Она читает актуальную ветку main, обновляет данные и публикует только `data/pets.json`
через GitHub. Для выполнения нужны включённый компьютер, работающий Codex и
доступный GitHub Connector. Это не GitHub Actions cron и не триггер обновления Roblox.
Если вики ещё не обновлена, новые питомцы появятся после следующей успешной проверки.
Дата `checkedAt` означает успешное чтение источника, а не подтверждение данных разработчиком.
Публикация: только отдельный репозиторий `sibatlet/steal-an-egg-guide`, ветка main.
Перед записью сравнивать текущий SHA, сохранять изменения пользователя.
При ошибке источника или публикации сохранять последнюю рабочую версию и сообщать об ошибке.
